## Anonymizing Participant IDs

To anonymize participant IDs (when preparing data to be shared):
Use the following script and change the seed for every paper so that a given participant gets a different anonymized code each time.
That way, a participant can't be linked across multiple data files from multiple papers (which would make it more likely that the participant could be identified):

https://github.com/DevPsyLab/ZenodoTemplate/blob/main/Analyses/Code%20to%20anonymize%20participant%20ID.R

https://devpsylab.github.io/DataAnalysis/openScience.html#anonymizedID
